## Usage

```tsx
import { NewsletterCallout } from '@/components/NewsletterCallout/Component'

export function ArticleNewsletter() {
  return (
    <NewsletterCallout
      title="Keep reading"
      description="Get new articles in your inbox."
      action="/api/newsletter"
      legalText="No spam. Unsubscribe anytime."
    />
  )
}
```

## Content model

The component renders a plain HTML form. Your application owns the endpoint, consent rules,
submission response, and subscriber storage.
