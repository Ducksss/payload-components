## Content model

The first four fields come from the shared `heroFields` base. `video`, `poster`, and `proofItems`
define this full-bleed media variant.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the headline.' },
    title: { type: 'text', required: true, description: 'The hero headline.' },
    description: {
      type: 'textarea',
      required: true,
      description: 'Supporting copy beneath the headline.',
    },
    links: { type: 'array', required: true, description: 'One or two CTA links (min 1, max 2).' },
    video: { type: 'upload', required: true, description: 'Background video uploaded to Media.' },
    poster: {
      type: 'upload',
      required: true,
      description: 'Stable image fallback shown before playback and for reduced motion.',
    },
    proofItems: { type: 'array', description: 'Up to four short proof labels below the CTAs.' },
  }}
/>
