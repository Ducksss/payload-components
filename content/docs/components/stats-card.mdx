## Content model

`eyebrow` and `title` come from the shared `statsFields` base that every Stats variant spreads;
`metrics` is specific to this variant. The panel distributes its columns evenly from the row count,
so two, three, or four metrics all stay balanced without a layout setting.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title. Shared base field.' },
    title: { type: 'text', required: true, description: 'The stats band heading. Shared base field.' },
    metrics: { type: 'array', required: true, description: 'Two to four metrics, one per panel column.' },
  }}
/>

Each item in `metrics` carries:

<TypeTable
  type={{
    value: { type: 'text', required: true, description: 'Display value such as “+1,200” or “56%”.' },
    label: { type: 'text', required: true, description: 'Short explanation of the metric.' },
  }}
/>
