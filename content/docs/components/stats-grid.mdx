## Content model

`eyebrow` and `title` come from the shared `statsFields` base that every Stats variant spreads;
`description` and `metrics` are specific to this variant. Metric values stay strings, so editors can
enter percentages, signed values, counts, or abbreviated totals without formatting logic.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title. Shared base field.' },
    title: { type: 'text', required: true, description: 'The stats band heading. Shared base field.' },
    description: { type: 'textarea', description: 'Optional intro paragraph under the heading.' },
    metrics: { type: 'array', required: true, description: 'Two to eight metrics, laid out four per row on desktop.' },
  }}
/>

Each item in `metrics` carries:

<TypeTable
  type={{
    value: { type: 'text', required: true, description: 'Display value such as “90+” or “24/7”.' },
    label: { type: 'text', required: true, description: 'Short explanation of the metric.' },
  }}
/>
