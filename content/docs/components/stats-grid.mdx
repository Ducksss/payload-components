## Content model

`eyebrow`, `title`, and `description` come from the shared stats base at
`src/blocks/shared/statsFields.ts`, so editing them updates every installed stats block at once.
`metrics` and `footnote` are specific to this variant.

Metric values stay strings, so editors can enter percentages, signed values, counts, or abbreviated
totals without formatting logic.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title. Shared base field.' },
    title: { type: 'text', required: true, description: 'The stats section heading. Shared base field.' },
    description: {
      type: 'textarea',
      required: true,
      description: 'Primary supporting copy. Shared base field.',
    },
    metrics: { type: 'array', required: true, description: 'Two to four prominent metrics.' },
    footnote: { type: 'text', description: 'Optional measurement note rendered under the grid.' },
  }}
/>

Each item in `metrics` carries:

<TypeTable
  type={{

    label: { type: 'text', required: true, description: 'Short explanation of the metric.' },
    detail: {
      type: 'text',
      description: 'Optional qualifier under the label — a period, source, or caveat.',
    },
  }}
/>
