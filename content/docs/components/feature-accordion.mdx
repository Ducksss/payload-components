## Content model

The first three fields come from the shared `featureFields` base. `items` and `links` define this
interactive variant; icon choices come from the shared Feature icon map.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title.' },
    title: { type: 'text', required: true, description: 'The section heading.' },
    description: { type: 'textarea', description: 'Optional intro copy.' },
    items: {
      type: 'array',
      required: true,
      description: 'Two to six accordion rows synchronized with the media panel.',
    },
    links: { type: 'array', description: 'Up to two optional CTA links.' },
  }}
/>

Each item in `items` carries:

<TypeTable
  type={{
    title: { type: 'text', required: true, description: 'Accordion row heading.' },
    description: { type: 'textarea', required: true, description: 'Expanded supporting copy.' },
    icon: { type: 'select', description: 'Optional icon used when the item has no image.' },
    image: { type: 'upload', description: 'Optional media shown while the row is active.' },
  }}
/>
