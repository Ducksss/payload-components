## Content model

The first four fields come from the shared `heroFields` base. `metrics`, `productImage`,
`imageCaption`, and `proofItems` define this motion-led variant. All animation is presentation:
it runs from the `motion` package inside the installed component, honors `prefers-reduced-motion`
(a scoped CSS net renders the finished frame even without JavaScript), gates the pointer parallax
to hover-capable pointers, and never adds editor-managed fields. Every gradient in the aurora
field derives from the theme tokens via `color-mix`, so the block re-tints itself under any
theme scope.
