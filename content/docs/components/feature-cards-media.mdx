## Content model

The first three fields come from the shared `featureFields` base. `items` and `links` define this
media-card variant; icon choices come from the shared Feature icon map.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title.' },
    title: { type: 'text', required: true, description: 'The section heading.' },
    description: { type: 'textarea', description: 'Optional intro copy.' },
    items: {
      type: 'array',
      required: true,
      description: 'Two to four visual feature cards.',
    },
    links: { type: 'array', description: 'Up to two optional CTA links.' },
  }}
/>

Each item in `items` carries:

<TypeTable
  type={{
    title: { type: 'text', required: true, description: 'Feature card heading.' },
    description: { type: 'textarea', required: true, description: 'Feature card body copy.' },
    icon: { type: 'select', description: 'Optional icon beside the card title.' },
    image: { type: 'upload', required: true, description: 'Media displayed at a fixed 16:9 ratio.' },
  }}
/>
