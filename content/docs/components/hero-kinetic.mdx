## Content model

The first four fields come from the shared `heroFields` base. `marqueeItems`, `image`,
`imageCaption`, and `proofItems` define this editorial variant. All animation is presentation:
it runs from the `motion` package inside the installed component, honors `prefers-reduced-motion`
(the final state renders without JavaScript or motion, and the marquee becomes a static wrapped
row), and never adds editor-managed fields. The component splits the `title` string into balanced
line masks itself and sets the closing word in the theme's serif accent — no extra fields.
