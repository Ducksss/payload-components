## Content model

The `eyebrow`, `title`, and `description` heading fields come from the shared
Testimonials family base (`src/blocks/shared/testimonialFields.ts`); the `testimonials`
bento is specific to this variant.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Optional small label shown above the title.' },
    title: { type: 'text', required: true, description: 'The section heading.' },
    description: { type: 'textarea', description: 'Optional intro paragraph shown under the heading.' },
    testimonials: {
      type: 'array',
      required: true,
      description: 'The bento cells (min 1, max 8). Mark one as featured for the large cell.',
    },
  }}
/>

Each item in `testimonials` carries the shared one-quote shape plus bento extras:

<TypeTable
  type={{
    quote: { type: 'textarea', required: true, description: 'The testimonial text.' },
    author: { type: 'text', required: true, description: 'Name of the person quoted.' },
    role: { type: 'text', description: 'Optional role / company shown under the name.' },
    avatar: { type: 'upload', description: 'Optional avatar image (Media upload).' },
    logo: { type: 'upload', description: 'Optional company logo shown above the quote (Media upload).' },
    featured: { type: 'checkbox', description: 'Give this testimonial the large bento cell.' },
  }}
/>
