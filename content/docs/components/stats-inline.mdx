## Content model

`eyebrow` and `title` come from the shared `statsFields` base that every Stats variant spreads;
`description` and `metrics` are specific to this variant. Each row renders as `value` followed by
`label`, so write labels that complete the sentence — `99.9%` + `uptime guarantee.` reads as one line.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title. Shared base field.' },
    title: { type: 'text', required: true, description: 'The stats band heading. Shared base field.' },
    description: { type: 'textarea', description: 'Optional intro paragraph under the heading.' },
    metrics: { type: 'array', required: true, description: 'Two to six figures, one per row.' },
  }}
/>

Each item in `metrics` carries:

<TypeTable
  type={{
    value: { type: 'text', required: true, description: 'Leading figure such as “99.9%” or “10M+”.' },
    label: { type: 'text', required: true, description: 'The rest of the sentence, including its full stop.' },
  }}
/>
