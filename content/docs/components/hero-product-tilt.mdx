## Content model

The first four fields come from the shared `heroFields` base. `productImage`, `imageCaption`, and
`proofItems` define this product-led variant.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the headline.' },
    title: { type: 'text', required: true, description: 'The hero headline.' },
    description: {
      type: 'textarea',
      required: true,
      description: 'Supporting copy beneath the headline.',
    },
    links: { type: 'array', required: true, description: 'One or two CTA links (min 1, max 2).' },
    productImage: {
      type: 'upload',
      required: true,
      description: 'Product image rendered in the perspective frame.',
    },
    imageCaption: { type: 'text', description: 'Optional visible caption beneath the image.' },
    proofItems: { type: 'array', description: 'Up to four short proof labels below the CTAs.' },
  }}
/>
