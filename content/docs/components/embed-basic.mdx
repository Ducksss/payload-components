## Content model

The block accepts approved HTTPS provider embed URLs — paste the provider's _embed_ URL (e.g.
`https://www.youtube.com/embed/VIDEO_ID`, not the watch URL). The iframe renders with a sandbox
and a narrowed permissions policy.

<TypeTable
  type={{
    url: {
      type: 'text',

    title: {
