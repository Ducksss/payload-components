## Content model

`eyebrow` and `title` come from the shared team base at `src/blocks/shared/teamFields.ts`, and each
member reuses the shared `teamMemberFields` shape so a person looks the same across every team
variant. This block appends a required `bio` to that shape — the compact `team-grid` and
`team-roster` layouts have no room to render one, so it stays off their schemas.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title. Shared base field.' },
    title: { type: 'text', required: true, description: 'The team section heading. Shared base field.' },
    description: { type: 'textarea', description: 'Optional intro under the heading.' },
    members: { type: 'array', required: true, description: 'One to eight team members.' },
  }}
/>

Each item in `members` carries:

<TypeTable
  type={{
    avatar: { type: 'upload', required: true, description: 'Member photo from Media. Shared member field.' },
    name: { type: 'text', required: true, description: 'Member name. Shared member field.' },
    role: { type: 'text', required: true, description: 'Job title or role. Shared member field.' },
    href: { type: 'text', description: 'Optional profile link. Shared member field.' },
    bio: { type: 'textarea', required: true, description: 'Short biography rendered under the name.' },
  }}
/>
