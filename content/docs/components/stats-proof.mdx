## Content model

This standalone Stats block keeps metric values as strings, so editors can enter percentages,
signed values, counts, or abbreviated totals without formatting logic.

<TypeTable
  type={{
    eyebrow: { type: 'text', description: 'Small label shown above the title.' },
    title: { type: 'text', required: true, description: 'The proof section heading.' },
    description: { type: 'textarea', required: true, description: 'Primary supporting copy.' },
    body: { type: 'textarea', description: 'Optional longer narrative.' },
    metrics: { type: 'array', required: true, description: 'Two to four prominent metrics.' },
    quote: { type: 'textarea', required: true, description: 'Customer proof statement.' },
    author: { type: 'text', required: true, description: 'Name of the person quoted.' },
    role: { type: 'text', description: 'Optional role and company.' },
    logo: { type: 'upload', description: 'Optional customer logo from Media.' },
  }}
/>

Each item in `metrics` carries:

<TypeTable
  type={{
    value: { type: 'text', required: true, description: 'Display value such as “56%” or “22M”.' },
    label: { type: 'text', required: true, description: 'Short explanation of the metric.' },
  }}
/>
