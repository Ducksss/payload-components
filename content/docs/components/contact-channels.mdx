## Content model

`eyebrow`, `title`, `description`, and the per-channel shape come from the shared contact base at
`src/blocks/shared/contactFields.ts`, so a channel validates and renders the same way in every
contact variant. Use this block when the form lives elsewhere — a dedicated contact route, a
Payload form-builder page, or a scheduling tool — and the page only needs to route people.

Each channel's `value` is validated on save: an `email` must parse as an address, a `phone` must be
7–15 digits, and a `url` must be an HTTPS URL or a same-origin path. A value that would not resolve
to a safe href is rejected in the admin, and the renderer falls back to plain text rather than
emitting a dead link.
