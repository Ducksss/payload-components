# Frameworks ’26 (event-conference) — asset provenance

Frameworks ’26 is a fictional design + engineering conference built as a
**Concept preview**. It is not a real event. Its name, edition count, dates,
venue ("Halle Nord"), speakers, programme committee, sponsors, testimonials,
ticket waves, and every metric are invented for this concept. Any resemblance to
a real conference, company, or person is coincidental.

The one real-world proper noun is the host city, Berlin, plus the neighbourhood
landmarks used to make the travel copy read like a working event page (BER,
Ostkreuz). No real venue, organiser, or trademark is named or depicted.

## Runtime assets

`assets: []` in `src/lib/templates/event-conference.ts` — this concept ships and
hotlinks **no raster runtime assets at all**.

- Every image surface is **token-derived**. The demo twins render their
  backend-free `bg-muted` placeholders, and
  `src/components/site/templates/event-conference/theme.css` paints them as
  duotone plates: a raking gradient in one of three violet/indigo inks
  (`--fw-ink-violet` / `--fw-ink-indigo` / `--fw-ink-orchid`), a highlight
  bloom, and a 6px halftone dot screen. Speaker "portraits" are therefore
  abstract plates — **no likeness, real or synthetic, is depicted anywhere**.
- The home hero's atmosphere (aurora arch, curtain rays, drifting glows, the
  schedule-board panel and its chart) is generated by the `hero-aurora` block
  itself from `--brand` / `--brand-100` / `--brand-200` / `--primary` via
  `color-mix`. This template only retunes those tokens.
- Sponsor marks in the logo cloud come from the shared demo twin
  (`src/components/site/demos/DemoLogos.tsx`) — invented monochrome lockups for
  fictional companies, carrying no third-party trademark.
- Typography uses only the fonts the root layout already loads via `next/font`
  (Geist Sans, Geist Mono, and Instrument Serif for the hero's one italic
  closing word). This template adds no font files.
- The theme's darkness is entirely scoped tokens under
  `[data-template-theme='event-conference']`. The site itself stays
  forced-light; nothing here touches `:root`, `.dark`, or `globals.css`.

## Generated posters

`public/templates/event-conference/posters/*.jpg` are **build artifacts** —
deterministic screenshots produced by `tools/templates/capture.ts`
(`pnpm templates:capture`) from this repository's own preview routes at the
template's current `revision`. They are screenshots of this repository's
rendered output and carry the repository license. Regenerate them whenever the
concept's visual direction changes, and bump `revision` in the same change.
